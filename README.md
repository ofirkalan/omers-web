# BACKROAD — אתר אביזרי עור לאופנועים

אתר חנות סטטי (HTML / CSS / JavaScript בלבד), בעברית ובכיוון RTL,
שנבנה לפי האפיון בקובץ `אפיון אתר חדש.xlsx`.

## הפעלה

אין צורך בהתקנה, בשרת או ב-npm. פשוט פותחים את `index.html` בדפדפן.

לפיתוח נוח יותר (כתובות נקיות, ללא מגבלות `file://`) אפשר להריץ שרת מקומי:

```bash
python -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```

## מבנה הקבצים

```
index.html        עמוד הבית — גיבור, קטגוריות, מוצרים נבחרים

product.html      עמוד מוצר — בורר גוונים, כמות, הוספה לעגלה   (product.html?id=<מזהה>)
cart.html         עגלת הקניות
checkout.html     תשלום
story.html        סיפור המותג
contact.html      יצירת קשר

```

## עריכת מוצרים ומחירים

הכל נמצא בקובץ אחד: **`js/data.js`**. אין צורך לגעת בשום קובץ אחר.

```js
{ id: 'grips-leather', name: 'גריפים מעור', category: 'bars', price: 299,
  variants: shades(7), variantLabel: 'צבע',
  desc: 'זוג גריפים עטופי עור בתפירה ידנית.' }
```

* `price` — **המחירים כרגע הם מחירי הדגמה שהומצאו.** מחליפים במספרים האמיתיים.
* `variants: shades(N)` — N הגוונים הראשונים מלוח העור שבראש הקובץ.
  לשינוי הגוונים עורכים את האובייקט `LEATHER`.
* `variants: types(N, 'סוג')` — כשהמספר באפיון מציין סוג ולא צבע (למשל תושבות לאוכף).
* `FEATURED` בסוף הקובץ — אילו מוצרים מופיעים ב"נבחרי הבית" בעמוד הבית.

הגדרות כלליות (טלפון, אימייל, כתובת, סף משלוח חינם) נמצאות באובייקט
`STORE` בראש `js/store.js`.

## הוספת תמונות

כל עוד אין תמונה — מסגרת התמונה נשארת ריקה, והאתר עובד כרגיל.

**תמונות מוצרים:** מעלים לתיקייה `images/products/` בשם
`<id של המוצר>.jpg` — לדוגמה:

```
images/products/grips-leather.jpg
images/products/backpack-eastwood.jpg
images/products/tank-pad-diamond.jpg
```

רשימת כל המזהים נמצאת ב-`js/data.js` (השדה `id` של כל מוצר).
יחס מומלץ: 4:5 לאורך (למשל 1000×1250 פיקסלים).

**תמונות מותג:**

```
images/brand/workshop.jpg    עמוד הבית — קטע "נולד במוסך"
images/brand/story-1.jpg     עמוד הסיפור — פרק 1
images/brand/story-2.jpg     עמוד הסיפור — פרק 2
images/brand/story-3.jpg     עמוד הסיפור — פרק 3
```

אם רוצים סיומת אחרת (`.png`, `.webp`) — משנים אותה בפונקציה
`productImage()` ב-`js/store.js`.

## עגלה ותשלום

העגלה נשמרת ב-`localStorage` של הדפדפן (מפתח `backroad_cart_v1`),
כך שהיא נשמרת גם אחרי רענון או סגירת הדפדפן.

**התשלום כרגע במצב הדגמה.** הטופס בודק את כל השדות (כולל בדיקת
ספרת ביקורת של מספר הכרטיס ותוקף), מייצר מספר הזמנה ומציג אישור —
אבל **לא מבצע חיוב אמיתי**.

אתר סטטי אינו יכול לסלוק כרטיסי אשראי בעצמו. כדי לחבר סליקה אמיתית
עורכים פונקציה אחת בלבד — `processPayment()` בסוף `js/checkout.js`.
שם כתובות הוראות מפורטות לשלוש אפשרויות:

1. ספק ישראלי (טרנזילה / קארדקום / Grow) — הפניה לעמוד סליקה מאובטח
2. Stripe Checkout — דורש שרת קטן שייצור session
3. PayPal — הטמעת ה-SDK

> חשוב: לעולם אין לשלוח מספרי כרטיס אשראי מהדפדפן לשרת שלכם.
> ספק הסליקה חייב לקבל אותם ישירות.

## טופס יצירת קשר

גם הוא אינו מחובר לשרת. לחיבור מהיר ללא כתיבת קוד שרת אפשר להשתמש
בשירות כמו Formspree / Web3Forms / Netlify Forms — משנים את תגית
ה-`<form>` ב-`contact.html` ל-`action` של השירות ומסירים את
מונע-ברירת-המחדל שב-JavaScript.
